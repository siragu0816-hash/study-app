# まいにち学習

英語・国語・数学I・Aの勉強時間を記録する、インストール不要のアプリです。数学I・Aは1つの科目として集計します。

## GitHub Pagesで無料公開する

公開用の構成を準備済みです。ビルドやサーバーのインストールは不要です。[公開手順](PUBLISH.md)を参照してください。公開URLで開く場合、ローカル版の記録はバックアップから復元します。

## Chromebookでローカルファイルを開く

1. `index.html` をChromebookに保存します。Linuxのファイルにある場合は「ファイル」アプリから「マイファイル」内の任意のフォルダにコピーしても使えます。
2. Chromeを開き、`Ctrl + O` を押します。
3. 保存した `index.html` を選び、「開く」を押します。
4. 開いたページをブックマークすると、次回から簡単に開けます。

Google公式のショートカット案内：https://support.google.com/chromebook/answer/183101?hl=ja

## 使い方

科目、勉強した日、時間と分を入力して「勉強時間を保存」を押します。今日・累計・科目別の時間が更新されます。過去の日付も記録できます。1回の記録は1分〜24時間です。間違えた記録は削除して登録し直してください。

## 追加機能

- 北海学園大学の受験日までの残り日数を表示します。初期設定は2027年度一般選抜A日程（2027年2月9日）。「受験日を変更する」でB日程（2月10日）や任意の日付を保存できます。当日は「今日が受験日」、翌日以降は「受験日を迎えました」と表示します。
- 1日の目標は3時間（180分）固定です。今日の全科目の合計から達成率を計算し、小数点以下は切り捨てます。3時間を超えると100%以上の数値を表示します。
- 連続勉強日数は、1分以上の記録がある日を数えます。今日が未記録なら昨日からさかのぼって数えます。今日と昨日が両方未記録なら0日です。3時間未満でも連続日数に含めます。
- グラフは今日を含む直近7日間の全科目の合計です。記録のない日は0分、破線は180分の目標を表します。
- 履歴の「削除」で確認後に記録を削除します。達成率・連続日数・グラフも再計算します。
- スマホでは画面下のナビゲーションから入力や履歴へ移動できます。

日付は使用端末の現地日付で計算します。公式入試日程（2026年9月7日確認）：https://www.hgu.jp/examination/examination-schedule.html

## 保存とバックアップ

記録と受験日の設定はブラウザのlocalStorageに保存されます。以前のバージョンの勉強記録も引き継ぎます。インターネット接続やアカウントは不要です。同じブラウザ・同じファイルの場所で使ってください。ファイルを移動・改名したり、別ブラウザで開いたりすると、以前の記録が表示されない場合があります。

「バックアップを保存」で記録のJSONファイルを保存できます。「バックアップを復元」で戻せます。復元は現在の記録を置き換えます。バックアップには勉強記録のみ含まれ、受験日の設定は含まれません。ブラウザのデータ削除や端末の変更に備え、定期的にバックアップしてください。シークレットモードでは使わないでください。端末間の自動同期はありません。

画面はスマートフォンの幅に合わせて1列になります。スマートフォンでローカルHTMLを開けるかどうかは、その端末やブラウザに依存します。

## 構成

`index.html` だけで動きます。外部ライブラリ、外部フォント、通信処理はありません。

JavaScriptの実行検証（DOM・保存領域の代替実装を使用）で、初期表示、目標達成率、連続日数、7日間の集計、残日数、うるう年の日付、記録の保存・削除、受験日設定を確認しました。この作成環境には利用できるブラウザがなかったため、実ブラウザ上の操作・表示確認は未実施です。
